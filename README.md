# Түйме — балаларға арналған пернетақта

Интерактивный сайт для детей: нажми любую клавишу — на экране появляется буква и смайлик с анимацией и звуком.

- 42 буквы казахского алфавита (А-Я)
- Озвучка букв детским голосом (Web Speech API)
- Звуковые эффекты (Web Audio API)
- Работает на телефоне и компьютере
- Без рекламы, без регистрации

## Локальный запуск

Просто открой `index.html` в браузере.

## Деплой на Vercel

Проект — статический сайт, деплоится как есть. `vercel.json` не требуется.

Live: будет доступен после деплоя через Vercel.

## Технологии

HTML + CSS + Vanilla JS, Google Fonts (Baloo 2, Nunito)
